(04)Method03 rules

How things get made.

Three habits that show up in everything on the shelf, whether it’s a security tool or a cat.

01

From zero

No templates, no page builders. This site is hand-written HTML, CSS and JavaScript. No framework, no build step. If I can’t explain how a thing works, I haven’t finished building it.

02

Assume it’s hostile

AiS treats the AI as the victim, never the safeguard. Spice and Qres inject nothing and read no game memory. The paranoid design is usually the one that survives.

03

Ship the alpha

Get it in front of people early, then say plainly what’s broken. The AiS page lists the three attacks that still get past it. That list is the point.
