/ 01 AiS Agent-in-Sandbox. AI editing agents never touch real files. Proposed edits run inside a disposable container, and a person approves them on a plain security-check screen. Anti-cheat for AI. python · docker · security Alphav0.1.6
/ 02 Spice A desktop overlay for gamers. Crosshairs, custom images and input visualizers over any game, on any monitor. Anti-cheat-conscious by default. electron · react · win32 Alphav0.1.3
/ 03 Qres Press a key, your resolution changes. Stretched-res toggling, refresh-rate control and game profiles, from the tray. electron · c# · win32 Shippedv1.0.3
/ 04 clipped Twitch clips in, YouTube Shorts out. Finds what’s trending, burns in word-by-word captions, writes the title and uploads, after you approve it or on autopilot. python · ffmpeg · whisper Alphav0.1.0
/ 05 Watchparty Frame-synced video across browsers. YouTube and Twitch right on the site; the extension unlocks Netflix and other locked-down players. web · extension · websockets ShippedLive
/ 06 Sketch Fighter Draw a fighting-game stage on an index card, photograph it, and fight on it seconds later. Abandoned now, but the sample stages still play in the browser. flask · phaser · opencv AbandonedPlayable
/ 07 Pixel cat The cat wandering every page of this site. Naps, stalks your cursor, pounces when it gets close, and meows when you click it. js · svg · pixel art ShippedLive
/ 08 evzero.org The site you’re on. Warp-field heroes, a sticker menu, pages that slide over each other, and an obsessive amount of purple. No framework. html · css · js Shippedv3.1
/ 09 Valorant tracker Riot ID in, rank card and recent match log out. Henrik’s API, proxied server-side so the key never touches the browser. web · api · val Outdatedv0.1
