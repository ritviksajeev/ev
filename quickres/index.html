01 / Capability

What it
does.

01

Hotkey toggle

Bind a key — F6 by default — to flip between a native and a stretched mode. Works from inside a fullscreen game. Pick the pair once; the hotkey and the tray menu both use it.

02

Refresh rate, done right

Every change carries a rate. Leave it on Highest available and QuickRes asks for the fastest rate at that resolution — so dropping to 1440×1080 keeps your 240 Hz instead of quietly falling back to 60. Or pin one.

03

Grid built from your panel

No hardcoded list. QuickRes enumerates every mode your display reports and lays out the useful ones: native, the stretched widths that keep your vertical lines, and same-shape lower resolutions.

04

Game profiles

Name a process and a resolution. QuickRes switches when the game launches and restores native when it exits. No hotkey, no thinking. Presets for Valorant, CS2, Apex, Fortnite, Overwatch and more.

05

Per-monitor targeting

Auto changes whichever monitor your mouse is on when the hotkey fires — the one you're playing on. Or pin a specific display. Plugging a monitor in re-reads everything.

06

A real safety net

Changes made in the window start a 15-second countdown and revert themselves if you never confirm, so a mode your monitor can't display never leaves you on a black screen. Hotkey switches skip the dialog — nothing lands on top of your game.

02 / Under the hood

No native
module.

Node can't call Win32 display APIs on its own, and shipping a prebuilt binary or a native addon means an ABI to keep matched forever. QuickRes takes a third route.

01
A 500-line C# CLI

native/QuickResDisplay.cs enumerates displays and applies modes through ChangeDisplaySettingsEx, printing JSON.

02
Compiled on first run

With the csc.exe already inside Windows. Cached in %LOCALAPPDATA%, keyed by a hash of the source. No SDK, no node-gyp, no committed binary.

03
~20 ms a call

Every switch after that is a plain execFile. Fast enough that the hotkey feels instant, and the helper is runnable by hand if you ever want to debug it.

Anti-cheat

QuickRes calls the same Windows API the Settings app uses. Nothing is injected into any process, no game memory is read, no input is synthesised. The global hotkey is an OS-level key reservation, not a keyboard hook. There is nothing here for EAC, BattlEye or Vanguard to object to.

03 / One thing to set

GPU scaling,
once.

QuickRes sets the resolution. Whether the picture fills your panel or sits in black bars is your GPU's scaling setting — no application can change that for you. Set it once and forget it.

NVIDIA

Control Panel → Adjust desktop size and position → Scaling Full-screen, Perform scaling on GPU, tick Override the scaling mode set by games and programs.

AMD

Adrenalin → Display → GPU Scaling On, Scaling Mode Full panel.

Intel

Graphics Command Center → Display → Scale Full Screen.
