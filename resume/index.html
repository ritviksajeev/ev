Projects

AiSExecution-verified sandbox for AI coding agents

Independent · 2026

Python · Docker · SQLite · v0.1.6-alpha, MIT, public on GitHub

  • Built a sandboxing system that runs AI-proposed code edits in disposable, network-isolated Docker containers and requires human approval before any real file is touched.
  • Implemented a 21-rule detection engine on CPython audit hooks (PEP 578) that attributes every file, network and subprocess event to its source line, plus a SHA-256 hash-chained audit log and a differential execution oracle.
  • Ran a blind adversarial red-team evaluation (attack catalog grown from 12 to 25): caught 18 of 21 exploits with 0 false positives on benign edits. 437 automated tests, about 0.5 s per verification.

Spice & QresWindows system utilities for gamers

Independent · 2026

Electron · React · TypeScript · Node.js · C# · Win32 API · MIT

  • Spice: a desktop overlay (crosshairs, input visualizers) built to be anti-cheat-conscious, with no code injection, memory access or synthetic input. Works alongside EAC, BattlEye, FACEIT and Vanguard.
  • Qres: a hotkey resolution and refresh-rate switcher that bridges Node.js to a native C# Win32 helper compiled on first run (no node-gyp, no prebuilt binaries), at about 20 ms per switch, with per-game profiles and an auto-revert safety net.

AI-assisted CPU schedulingfor mixed workloads

Team · 2026

Rider University, CSC-240 term project · Python · scikit-learn

  • Built a two-level online learning framework (SGDClassifier) that predicts the best CPU scheduling algorithm from live ready-queue features, cutting average waiting time by 22 to 43% against static algorithms (FCFS, SJF, RR, Priority) across 2,250 simulated scenarios, validated with SHAP feature-importance analysis.
