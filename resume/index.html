Profile

I study cyber security and spend the rest of my time shipping side projects in public: a sandbox that checks what AI coding agents actually do, desktop tools for people who play competitive games, and a way to watch video in sync. I build everything from zero, I write down what my tools cannot do, and I would rather show working code than describe it.

Selected projects

AiSAgent-in-Sandbox

Python · Docker · v0.1.6-alpha
  • A mediation layer that keeps AI coding agents away from real files: every proposed edit runs in a locked-down container, and a person approves it on a plain security-check screen.
  • 21 detection rules, a hash-chained audit log and 437 tests. A red-team harness generates new attacks and scores them blind: 18 of 21 caught, with no false positives.

SpiceDesktop overlay for gamers

Electron · React · TypeScript · v0.1.3-alpha
  • A transparent, always-on-top overlay that puts crosshairs, custom images and input visualizers over any game on any monitor.
  • Designed around anti-cheat from the start: no process injection, no game memory access and no synthetic input.

QresResolution hotkeys for Windows

Electron · C# · Win32 · v1.0.3
  • A tray app that switches display resolution and refresh rate from a global hotkey or per-game profiles, with a countdown that reverts a mode the monitor cannot show.
  • The Win32 layer is a small C# command-line tool the app compiles on first run, so there is no native module to keep in step.

WatchpartySynced video across browsers

Node · WebSockets · browser extension
  • Keeps YouTube and Twitch in step for everyone in a room through a small WebSocket relay, with an extension that does the same on sites that block embedding.
