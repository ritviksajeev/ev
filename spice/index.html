01 / Capability

What it
does.

01

Crosshair overlay

Six built-in presets (classic, dot, cross, circle, T, chevron) with full color, opacity, scale, and outline control. Or upload your own PNG / GIF / WEBP — the image overrides the preset and renders at any scale, dead-center on the chosen display.

02

Custom image library

Drop logos, animated GIFs, anything. Each image gets its own opacity, scale, X/Y, visibility, and pin. Drag-resize handles in preview mode. Pin a position and it survives every restart.

03

Multi-monitor display picker

Settings → LIVE OVERLAY lists every connected display with resolution + scale factor + a primary marker. Switch the overlay to the monitor you actually game on with one click.

04

Profiles + persistence

Save multiple loadouts (avatar, bio, full widget setup) and swap between them. Everything — accent color, display choice, widget positions — survives restart, stored locally in %APPDATA%\spice\.

05

Tray-resident, hotkeys

Closing the manager hides it to the system tray — the overlay keeps running. Right-click tray for show / toggle / quit. Global hotkey Ctrl + Alt + Shift + Q kills the overlay from anywhere if it ever misbehaves.

06

Auto-update on launch

Pings evzero.org/spice 1.5 s after launch. New build available? Settings → ABOUT → UPDATES shows a card with release notes and a one-click download link. Settings persist across upgrades.

02 / Safety

Anti-cheat
conscious.

By default, Spice does nothing a strict anti-cheat would object to. The overlay is a transparent always-on-top window — same OS surface as the Steam, Discord, and OBS overlays.

Spice does NOT
  • Inject any code into game processes
  • Read or scan game memory
  • Send synthetic keystrokes or mouse events
  • Modify game files
  • Make network calls (except the version-check ping to evzero.org)
Optional: GAME INPUT MIRROR

For the WASD + mouse-button visualizers to react to in-game input, Spice needs a passive low-level OS hook (SetWindowsHookEx WH_KEYBOARD_LL) — same kind Discord and OBS use. Off by default.

  • ✓ EAC, BattlEye, FACEIT, ESEA, Vac
  • ⚠ Vanguard (Valorant) — leave OFF before launching
