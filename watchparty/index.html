Netflix, Disney+, HBO?
Use the extension

Those sites block embedding, so the extension syncs the player on their own page instead. It speaks the same protocol, so it stays in step with people watching here.

Works on Chrome, Brave, Edge, Opera, Arc.

  1. Unzip the downloaded file.
  2. Open chrome://extensions.
  3. Toggle Developer mode (top right).
  4. Load unpacked → pick the unzipped folder.
  5. Pin the extension, open Netflix / YouTube / Twitch, click the icon.
